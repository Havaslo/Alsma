# Запрос в T2 ATS по подключению голосового агента

**Тема:** Подключение входящих звонков номера +7 930 283-88-28 к голосовому AI-агенту

Здравствуйте!

Используем T2 ATS, номер: **+7 930 283-88-28**. Хотим подключить русскоязычного голосового автоответчика для входящих звонков 24/7. На первом этапе агент отвечает по базе знаний, принимает заявку и при необходимости переводит звонок менеджеру.

Просим предоставить:

1. Документацию и доступ к API или SIP-интеграции для входящих звонков.
2. Возможность направлять звонок на внешний SIP/WebRTC/медиа-шлюз с двусторонним аудио в реальном времени.
3. Формат webhook-событий: начало, ответ, завершение, перевод, занято, ошибка; включая ID звонка, номер клиента, длительность и статусы.
4. Возможность перевода вызова на внешний номер менеджера и получения результата перевода.
5. Возможность получить аудиозапись или раздельные аудиоканалы клиента и оператора/агента.
6. Требования к IP allowlist, TLS, авторизации, кодекам, DTMF и ограничениям по длительности.
7. Тестовый режим, тестовый номер или безопасный способ проверить маршрутизацию без влияния на основной номер.
8. Ограничения тарифа на запись, передачу аудио и одновременные линии.

Просим также уточнить, поддерживается ли SIP REFER/attended transfer или иной механизм перевода на менеджера, а также можно ли сохранить ссылку на запись и передать её через webhook после завершения звонка.

Контакт технического специалиста и реквизиты проекта готовы предоставить по защищённому каналу.
