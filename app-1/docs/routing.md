# Routing

- TanStack Router owns the application entrypoint and generated route tree.
- Every user-facing URL has a `createFileRoute` declaration under `src/routes`.
- `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin. Never edit, format, or
  lint it manually.
- Keep `route-constants` as the flat route catalog used by Amazi preview navigation and by product
  links, redirects, and route-aware UI.
- Use TanStack Router `Link`, `Navigate`, `useNavigate`, `useParams`, and `useRouterState` for
  client navigation and route state. Do not add React Router dependencies or compatibility layers.
- Keep wildcard and other non-navigable route patterns out of the preview route catalog.
- The root route provides the application providers, not-found redirect to `/`, and error boundary.
- Keep backend `/api` endpoint paths out of `route-constants`.
