## Документы на странице «О нас»

Документы отображаются в коллекции `about/documents` под контактами. В админке «Управление сайтом → Документы» их можно добавлять в формате PDF, переименовывать, удалять из публикации и сохранять изменения; новые файлы добавляются в конец коллекции. Для уже загруженных managed PDF доступна кнопка «Создать превью» или «Обновить превью», которая повторно рендерит первую страницу целиком.

Публичная страница разрешает ссылки и превью управляемых файлов через backend media endpoint, поэтому загруженный PDF открывается как документ, а не как маршрут frontend-сайта.

Превью стартовых документов — это отдельные JPEG первой страницы, а не встроенный PDF-ридер. При загрузке PDF backend рендерит первую страницу целиком и возвращает `previewUrl`, который сохраняется в коллекции документа.

## Навигация админки

В боковом меню раздела «Управление сайтом» остаются пункты для главной страницы, проживания, SPA, развлечений, акций, новостей, блога, документов и общих настроек. Разделы «Торжества» и «Всё включено» скрыты только из навигации; связанные маршруты и публичные страницы не удаляются.
