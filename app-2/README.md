## PDF-документы сайта

Медиа-эндпоинт управления сайтом принимает PDF-файлы, которые используются коллекциями документов публичных страниц.

При загрузке PDF медиа-эндпоинт дополнительно извлекает первую страницу сканированного документа как JPEG и возвращает `previewUrl`; основной PDF и превью хранятся в managed storage отдельно. Публичный `GET /api/media/managed/:objectToken` проксирует содержимое файла через backend вместо редиректа на внешний storage-домен. Это позволяет браузерам открыть PDF и превью без блокировки перехода политикой COOP.
