# Фиксация согласий сайта

Версия текста юридических документов хранится в `src/lib/legal/consent.ts` и должна совпадать с версией frontend `LEGAL_DOCUMENT_VERSION`.

- Заявки сайта сохраняют отдельные серверные записи согласия на обработку данных и (только при выборе каналов) рекламу в `site_leads.details.legalAcceptances`.
- Обращения в чат сохраняют согласие на первое сообщение в `admin_requests.details.legalAcceptances`.
- Принятие пользовательского соглашения при запросе входного кода хранится в `guest_email_verifications.legal_acceptances`.
- Принятие оферты перед оплатой услуги хранится в `service_orders.legal_acceptances`.

Запись включает тип, версию текста, цель, адрес страницы, действие и серверное время подтверждения; канал рекламных сообщений сохраняется отдельно. Новые структурированные поля добавляются обычными совместимыми Prisma-миграциями. Не включать детали согласия в публичные ответы API без необходимости.

При изменении юридического текста синхронно обновлять версии документов, frontend и backend; проверить активные формы и существующий чекаут. Онлайн-бронирование проживания сейчас отключено и пока не записывает акцепт оферты.
